# B4O7

一周就像七场系列赛。你要做的，是赢下其中 4 天。

B4O7 是一个放在自己手机上的习惯记录。没有账号，没有服务器，也没有统计追踪。目标、睡眠、日记和奖励图片都只存在这台设备的浏览器里。第一次打开并载入之后，没有网络也能用。

每个目标各自记一周的比分，不会合成一个总分。

图标是一圈七段弧：四段灰绿、三段石墨色，中间是 B4。页眉用同一枚环。每个目标的一周也画成七段：绿色是赢，红色是输，灰色是还没记，更暗的一段是休息日。

## 用 GitHub 网页把它发布出去

全程在 GitHub 网站上完成。不需要安装 Git，也不需要在电脑上构建。

1. 解压 `b4o7-site.zip`。里面应有 `index.html`，以及 `css`、`js`、`icons` 文件夹，还有说明文件。
2. 打开 [github.com](https://github.com)，点右上角 **+**，选 **New repository**。
3. 仓库名填 `b4o7`。选 **Public**（免费的 GitHub Pages 需要公开仓库）。不要勾选添加 README、许可证或 .gitignore，避免和你上传的文件混在一起。
4. 创建后，在空仓库页面选择上传已有文件（uploading an existing file）。
5. 把解压出来的文件和文件夹拖进去。上传的是里面的内容，不是那个 zip 本身。
6. 提交这次上传。
7. 打开仓库的 **Settings → Pages**。
8. **Build and deployment** 里，Source 选 **Deploy from a branch**。
9. 分支选 **main**，文件夹选 **/ (root)**，保存。
10. 等一两分钟。页面上会出现网址，样子类似 `https://你的用户名.github.io/b4o7/`。

网址里带着仓库名，这是正常的。页面里的链接都是相对路径，放在子目录下也能打开。

不要把备份用的 JSON 文件传到这个仓库。网站文件里没有你的个人记录。记录只留在手机上。

## 在 iPhone 上安装

1. 用 **Safari** 打开上面的网址。iPhone 上的 Chrome 不能加到主屏幕。
2. 点底部分享按钮。
3. 选 **添加到主屏幕**，再点 **添加**。
4. 从主屏幕打开 **B4O7**。它会全屏显示，不再有 Safari 的地址栏。

第一次打开需要联网，手机会把应用存下来。之后断网也能用，直到你更新它。

在 Mac 上用浏览器打开同一个网址即可。页面会收在中间一栏，方便阅读。

## 一周怎么算

- 每周目标可以设成 1 到 7 天，默认是 4。
- 今天没完成时是「待定」，不会被记成失败。
- 已经过去、又没有赢下的日子记为失利。休息日，以及这个目标还不存在的日子，不算失利。
- 休息日是中性的。如果休息日太多，导致目标根本达不到，设置时不会让你保存。
- 赢的天数达到目标，这一周的系列赛就赢了。之后还可以继续记，多出来的胜利也算数。
- 如果剩下的日子已经不够达到目标，或者这一周结束时没有达到，系列赛就结束。
- 以后修改目标，不会改写已经过去的周。每一周都会留下当时的设置。
- 一周从周一开始，或从周日开始，在设置里选。建议一开始就定好。如果以后改了，旧的目标数字仍会保留。

睡眠有单独的一页。一夜记在你醒来的那个日期上。入睡、醒来和间隔都会连同时区一起保存。例如「7h 53m」只是记录下来的间隔，不是医学结论。只按了入睡、还没有醒来时，这一夜保持未完成，不会编造时长。手动改正过的记录会标成「已更正」。

## 备份和恢复

设置里的 **Export backup** 会下载一个 JSON 文件。笔记、睡眠和你上传的图片都在里面。iPhone 的 Safari 可能会把它放进下载文件夹。请把它移到「文件」App，或你信任的其他地方。

**Export history CSV** 是一份不含图片的历史表格。

**Import backup** 有两种方式：

- **Merge（合并）**：按编号加入或更新，手机上其余记录保留。
- **Replace（替换）**：先清掉这台手机上的数据。需要输入 `REPLACE`。

**Delete all data（删除全部）** 需要输入 `DELETE`。

设置里的 **Load demo data** 会加入示例目标，方便你先看看界面。它不会删掉你自己的记录。旁边可以移除示例。示例不会自动出现。

建议每隔一两周导出一次备份。等你有了自己的记录、又一段时间没有备份时，首页会轻轻提醒一次。

## iPhone 上的限制

- **提醒。** 没有服务器会来叫你。iOS 也不会在后台一直运行这个应用。只有在 B4O7 开着的时候，到点才会出现提醒。通知权限不是必须的，开了也只在应用开着时有用。
- **存储。** 手机空间不够，或很久没有打开，iOS 有可能清掉网站数据。B4O7 会请求系统尽量保留，但系统可以拒绝。真正保险的是你导出的备份文件。
- **离线。** 第一次成功打开之后，应用会留在手机里。如果你清除 Safari 的网站数据，或者连同网站数据一起删掉主屏幕图标，记录会一起消失。做这些之前先导出备份。
- **更新。** 手机会继续用旧版本，直到它能下载到新版本。步骤见下。

## 如何更新

1. 下载新的 zip 并解压。
2. 在 GitHub 上打开仓库，上传新文件。遇到同名文件时选择替换。
3. 等 Pages 部署完成。
4. 手机联网时打开 B4O7。如果出现「有新版本」的提示，点 **Reload**。
5. 如果还是旧的，先用 Safari 打开一次网址，再从主屏幕进入。只删掉主屏幕图标通常不会删记录，但更新前仍建议先导出备份。

## 只在自己电脑上看一看

在含有 `index.html` 的文件夹里运行：

```bash
python3 -m http.server 8741
```

打开 `http://127.0.0.1:8741`。不要直接双击 `index.html`。它需要一个网址才能把数据存下来。

计分规则有自动测试，使用应用时不必运行：

```bash
node --test tests/*.test.js
```
